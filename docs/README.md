# 给同学和 AI 的文档入口

适用于 `bigscity-hugo` 原版还原迁移，不适用于旁边旧 `web` 镜像或 redesign 备份。

## 最短上手路径

1. 在 Codex 或类似工具中打开 **bigscity-hugo 项目根目录**，不要只打开旧 web 文件夹。
2. 让 AI 阅读 [项目速览](01-项目速览.md) 和 [AI 内容维护指南](02-AI内容维护指南.md)。根目录 `AGENTS.md` 是自动入口，但不是所有工具都会自动读取它。
3. 从 [任务提示词](03-任务提示词.md) 选择任务，填入实际文字、附件和要求。
4. AI 修改源文件并验证；你检查预览；确认后再明确要求部署。

不懂路径也可以只说业务要求，例如“在成果栏目新增一个项目介绍，附件是……，首页加入口，但不要改导航”。AI 应负责确定文件、链接和模板。

## 文档分工

| 文档 | 用途 |
| --- | --- |
| [01 项目速览](01-项目速览.md) | 快速了解架构、位置和现状 |
| [02 AI 内容维护指南](02-AI内容维护指南.md) | 修改决策、各类任务分支、导航展开、验收和保护规则 |
| [03 任务提示词](03-任务提示词.md) | 可以直接复制的任务指令 |
| [04 Markdown 样例说明](04-Markdown样例说明.md) | 栏目首页 + 论文页样例的使用边界 |
| [完整使用说明](../使用说明.md) | 从环境准备、编辑、预览、构建到发布的全流程 |
| [进阶维护细节](06-进阶维护细节.md) | 保留此前 HTML 编辑、模板和部署的详细参考 |

样例源文件位于 `examples/content/`，不会自动生成网页。手册中的域名、年份、作者、链接和附件应替换为真实值。

## 任务交付前必须确认

- AI 没有改错旧 web 项目，没有覆盖你的其他修改。
- 页面文字真实；没有把示例作者、虚构结果或不存在的附件发布出去。
- 栏目入口与返回链接正常；桌面和手机的导航可用。
- 构建通过；生产发布需要单独授权。
